Đồng bộ GitHub

Mỗi lần mở trang, thư viện thuốc và đơn mẫu tự tải từ GitHub. Muốn thay đổi tự lưu lên GitHub thì cần token: nếu kho có file token.enc.json, trang sẽ hỏi mật khẩu để mở token (token chỉ giữ trong bộ nhớ trang, không lưu trên máy). Cũng có thể dán token vào ô dưới để dùng riêng cho máy này. Thông tin người bệnh không bao giờ gửi lên GitHub.

Tạo / đổi token.enc.json

Mã hóa token (ô phía trên) và chữ ký hiện tại bằng một mật khẩu, thành file token.enc.json để đặt trên GitHub. Mật khẩu này chính là mật khẩu trang hỏi mỗi lần vào. Kho là public nên hãy đặt mật khẩu dài, khó đoán.

Sao lưu thư viện

Chữ ký

Chữ ký nằm trong file token.enc.json (được mở cùng token khi nhập mật khẩu). Muốn dùng chữ ký khác riêng cho máy này thì bấm Chọn chữ ký (ảnh PNG/JPG hoặc file đơn thuốc cũ .html).
